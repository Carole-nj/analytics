Good ideas start with paying attention.

Welcome to Fieldnotes, a small demo website wired up to the visitor analytics tracker. Browse a few pages, then check the dashboard to see what was recorded.

01 / PAGE VIEWS

Move between pages

Use the navigation above. Each page load is recorded with its own URL and title.

02 / ACTIVE TIME

Stay a little while

03 / VISITS

Come back later

Reload or revisit to test returning visitors. A new session starts after 30 minutes idle.

When you have explored the demo, open the analytics dashboard to review your test visit.

About / page three

A simple place to try the tracker.

Fieldnotes is a local demo, not a real publication. Its pages are here to help you check that the analytics script is installed and sending events.

CHECK 01

Can you see visits?

Open the dashboard after loading this site. The visit should appear in the recent sessions list.

CHECK 02

Can you see page views?

Visit Home, Stories, and About. The dashboard should show the different page URLs.

CHECK 03

Can you see time?

Spend at least 15 seconds on a page to see a heartbeat update, then revisit the dashboard.

This demo uses the local track.js and track.php next to this file.
